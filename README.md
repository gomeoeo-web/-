# 期效管家 1.10.0

相機使用雲端辨識；使用者無需 API key、測試密碼或下載視覺模型。第一次辨識會說明照片上傳並徵求同意。預設物品資料與照片縮圖儲存在原裝置，既有資料鍵值未更動。第四頁「共享空間」使用獨立物品、照片、分類、封存／刪除資料；建立新空間從空白清單開始，加入空間只載入共享資料，不合併本機物品或套用本機設定。只有共享空間內的變更會同步至雲端。本機物品菜單的「加入共享空間」可建立獨立共享副本，保留本機原物品與設定；尚未連線時先建立或加入空間，再手動加入物品。

共享頁沿用 App 的卡片、圖示、色彩與四頁滑動導航，提供獨立分類篩選、排序與卡片檢視，以及手動新增、智慧輸入與鏡頭辨識確認。共享空間的顯示偏好與本機分開，主題與視窗尺寸沿用本 App 外觀，不從雲端覆寫。共享物品不加入現有本機通知排程。共享快取按空間識別碼保存於 `lifespan_shared_data_v1_*`，中斷裝置後仍保留快取；舊連線升級時先讀取雲端至獨立快取，不上傳本機物品。

共享物品直接使用主頁的詳情菜單與編輯表單，沿用新增確認、編輯自動儲存、複製、重設週期、待用／啟用和歷史紀錄。共享物品詳情菜單與主頁相同靠底部顯示，其他共享彈窗置中，沿用 App 的進出動畫、背景遮罩、按壓回饋、拖曳關閉與減少動態效果設定。共享頁控制區僅保留新增共享物品、共享物品排序（含自訂順序）及全部分類三個按鈕；菜單使用相同樣式的置中彈窗，所有變更只寫入共享空間。

補貨及批次管理功能已移除，包括主頁／分類／待用工具列、批次新增、物品菜單的加入補貨與重設週期後的補貨提示。既有備份中的補貨資料欄位保留相容性。

## 1.10.0 變更

- 編輯時清空名稱會保留原物品；儲存失敗保留編輯內容並支援重試或放棄，不套用未儲存的通知排程。延遲或亂序讀取的照片只套用至最新的圖片操作。
- 新增／編輯物品可用表情符號或最多兩個字作為圖片，即時預覽並支援待用、共享、備份及還原；可切換回自動圖示或上傳相片。
- 完整 JSON 備份包含使用中／待用、封存、最近刪除、照片、分類、排序、補貨及顯示設定；顯示上次匯出時間。匯入先驗證並預覽件數，再選合併或取代，套用前保存本機復原點。支援舊物品陣列與舊版備份；邀請碼、通知權限、辨識同意與額度不匯出。
- 包裝期限與開封後使用天數分開保存，以較早日期顯示及排程。待用期間不計開封期限；已設定開封天數的待用物品啟用時開始計算。
- 主頁、分類與待用清單支援緊湊清單顯示。
- 已移除「已用完」、「已丟棄」與「稍後處理」操作；既有封存紀錄仍保留。
- 日期來源標示為包裝辨識、推算、手動設定或既有資料。估算期限儲存前需明確勾選確認；手動改日期後標為手動設定。
- 提醒狀態顯示通知權限、提醒開關、已排程數量與下一次時間，Android 顯示精確鬧鐘權限。新增 30 秒延遲測試；網頁版明示關閉頁面後無法提醒。
- 第四頁家庭共享空間以邀請碼加入，可跨裝置獨立共享物品與照片、分類、封存／刪除。前景每 30 秒檢查，離線變更保存在共享快取；伺服器版本檢查防止互相覆蓋，有衝突時可先匯出共享備份，再合併或採用雲端資料。合併時同識別碼採用雲端內容。本機備份與共享備份分開匯出。
- Android versionName 1.10.0、versionCode 11000。

家庭共享使用新的 `SHARED_SPACES` Durable Object，須依 [backend/DEPLOY.md](backend/DEPLOY.md) 部署後才能連線。共享空間保存完整物品資料，與不儲存辨識照片的相機 API 分開。邀請碼有完整讀寫與刪除空間權限；中斷此裝置保留本機資料，刪除共享空間會使所有舊邀請碼失效。資料並非端對端加密。每份共享資料上限 4 MB，超過時保留本機資料並顯示錯誤。

## 用量與資料

目前辨識後端每個網路 IP 每日 200 次、全 App 每日 500 次；前端智慧鏡頭額度維持 50 次。每日以台灣時間 00:00 重置，相同 Wi-Fi 共用 IP 額度。送往模型的嘗試即計次，失敗也不自動退款或重試。共享空間另設每 IP 每分鐘 120 次請求、每日 10 次初次上傳限制。

額度由 Cloudflare Durable Object 儲存並原子保留，未設定儲存綁定時停止辨識。這是費用與流量保護，不是帳號驗證；攻擊者仍可能耗尽免費名額。後續大量公開使用時，可再加入 Turnstile / 登入。CORS 不是驗證身分的機制。

後端不儲存照片、提示詞、辨識內容或原始IP。只保留當日用量、加鹽雜湊的來源識別與每分鐘計數。Google/Cloudflare 仍依其服務條款處理請求。API 是否收費依開發者帳號方案而定，次數上限不保證固定金額。

## 建置與驗證

`npm install` 安裝依賴；`npm run build` 同步網站、字型與功能模組到 www，供 Capacitor 使用。

`npm test` 執行目前的資料、後端、額度、相機及手勢／本機啟動回歸測試。`npm run test:browser` 使用本機 Microsoft Edge 檢查 1.10.0 的清單、開封期限、備份、提醒、日期來源、兩裝置共享與離線同步。`npm run test:release` 同時執行以上測試與原有新增／編輯儲存回歸。相機與共享傳輸使用模擬回應及本機 Worker，不消耗雲端額度或上傳真實資料。`npm run test:legacy` 保留歷史 1.9 的文字／樣式斷言；其中含舊版版本號、舊供應商與舊介面預期，不作為 1.10.0 發行驗證。

本機測試不等於 iPhone/Android 實機驗證，也不等於正式雲端已部署。更新前請使用 App 設定頁匯出備份，尤其是不同裝置間移轉時。
